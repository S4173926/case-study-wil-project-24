# Materials not invented by this package

The application, available historical code, available result snapshots, original history bundle
and a shareable Trello evidence subset are included. The following must be added only when they
actually exist:

- The final written report and its Overleaf/LaTeX source, including working project links.
- Genuine individual reflections and the group-approved contribution documentation.
- Any actual mentoring records the team chooses and is permitted to share.
- Completed ratings or participant outcomes exported from teammates' local Workbenches.
- Any other final submission documents required by the applicable course instructions.

The source-release tests do not replace these materials. No report.pdf or meeting record has
been added merely to make the repository appear complete. Keep restricted signed/student-ID
forms outside a public repository; use the authorised submission channel.

The user-facing assistant is not being rebuilt or changed as part of this repository packaging.
