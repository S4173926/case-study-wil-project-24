# Source-linked catalogue

99 reusable paper-specific summaries, with 191 evidence spans in the unchanged 30-paper source collection. Entries include claim identifiers, facets, tags, original source spans and a pending independent-review field.

Drafting used a language model with source-based development checks. Matching citation offsets is a mechanical check, not an independent human judgement of the summary. Catalogue creation was informed by previously observed questions and errors; known-question results are development/regression evidence.

Release 1.2 changes the author/provenance wording only. Factual texts, ranking tags, facets, metrics and evidence are unchanged from the verified selection repair. The metadata edit changes the catalogue hash. The earlier repaired hash is explicitly recorded as a compatible answer set in `config/release_compatibility.json`; this does not rebrand an old run as newly executed.
