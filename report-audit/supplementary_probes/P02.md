### FLARE
In FLARE’s direct method, the model first generates a temporary next sentence and checks its token probabilities. Retrieval is triggered if any token is below the confidence threshold; if all tokens meet the threshold, the sentence is accepted without extra retrieval. When triggered, the system retrieves relevant documents and regenerates the sentence using them. [flare:s0015]

### FLARE
FLARE uses the anticipated next sentence to formulate a forward-looking search query. Its implicit query formulation masks low-confidence tokens so that uncertain or erroneous words do not dominate retrieval; the retrieved evidence is then used to regenerate the sentence. [flare:s0014] [flare:s0029]
